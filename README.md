## Project Overview

This repository contains our Exploratory Data Analysis (EDA) project for the **Car Evaluation Database** from the **UCI Machine Learning Repository** (1,728 records). 

We analyzed how 6 input specifications (buying price, maintenance cost, door count, passenger capacity, luggage boot size, and safety rating) determine whether a vehicle is evaluated as:
- `unacc` (Unacceptable)
- `acc` (Acceptable)
- `good` (Good)
- `vgood` (Very Good)

## Key Analysis Findings

1. **Safety is Mandatory:** 100% of vehicles with `low` safety (576/576) are evaluated as unacceptable (`unacc`).
2. **Capacity Filter:** 100% of 2-seater vehicles are rejected. A car must seat at least 4 passengers to be acceptable.
3. **Price Ceiling:** Very high purchase price or maintenance cost prevents vehicles from achieving `good` or `vgood` ratings.
4. **Requirements for 'Very Good':** Every single `vgood` car has high safety, seats 4 or more people, and has reasonable costs.
5. **Secondary Attributes:** Door count and boot size act as differentiators only after safety and capacity baseline checks pass.
